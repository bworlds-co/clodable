# Clodable 0.4.0

Released November 21, 2026. Clodable can follow Claude in French, and first-run saving checks now offer clearer failures and a working retry.

## What builders will notice

- **French across Clodable.** The panel, preview controls, activity, help requests and command-line messages use French when Claude’s language setting selects French. English remains the fallback for other languages. App content, code, paths and product names stay as they are.
- **Each conversation keeps its language.** Retained conversations reread Claude’s setting. The preview follows the conversation attached to it. Changing language keeps the selected app, account and move choices.
- **An honest Git check.** Clodable checks that Git works, rather than only finding it on the computer. On macOS, it checks Apple’s developer tools before invoking the placeholder that can open an installer. Saving setup stops before account or app creation if Git is unavailable.
- **A working Check again.** Failed tool preparation can be retried in the same conversation. Incomplete checks and late results cannot enable setup. You can keep shaping your local app while saving is unavailable.
- **Clearer GitHub recovery.** Network trouble, expired codes and declined authorization get different messages. If sign-in finishes but the account cannot be confirmed, **Check connection** verifies it again without starting another sign-in. **Ask Claude for help** includes useful diagnostic facts without credentials or temporary codes.

This release addresses the first recovery stage of [issue #9](https://github.com/bworlds-co/clodable/issues/9). Windows tool bootstrap and cleanup remain separate work; the issue stays open.

## Updating on another laptop

Update Clodable through Claude Desktop’s plugin settings and confirm version **0.4.0**. Start a new Code conversation. In an existing conversation, run `/reload-plugins --force`, then reopen Clodable. Restart an existing preview to load the updated runtime.

For a command-line plugin installation, run `claude plugin update clodable@clodable`. If the marketplace is pinned to an older release, use the current marketplace at `https://github.com/bworlds-co/clodable`, then update again.

The Desktop plugin contains its own CLI; no separate npm installation is needed. This GitHub release also provides `clodable-plugin-0.4.0.zip`, the matching standalone CLI archive `clodable-0.4.0.tgz`, and `SHA256SUMS`. The matching standalone CLI is available in the attached archive; npm registry publication is pending.

To check French, select French in Claude’s language setting and open Clodable in a new Code conversation. Check the panel and preview controls, then **Configurer l’enregistrement**. If a local tool fails, use **Vérifier à nouveau** after repairing it. If GitHub sign-in finishes but the account is not confirmed, use **Vérifier la connexion**.

## Verification and limits

All 276 package tests and 196 plugin tests pass. Lint, package and plugin type checks, builds and catalog coverage checks pass. The packaged CLI reports 0.4.0 and matches the plugin’s bundled CLI. The standalone package includes Clodable’s license and the notices for bundled dependencies.

Native Claude Desktop checks on engine 2.1.328 exercised unavailable Git, installer refusal, split sign-in codes, network failure, expiry, verification-only retry and recovery after failed tool preparation. These used simulated process results. The combined English/French behavior and language changes during a pending tool check are covered by automated plugin tests. A genuinely clean laptop still needs the real installer, network and keychain checks; that is the purpose of this release test.

This does not repeat a complete live migration or establish Windows first-run support. Email delivery, hosted sign-in and AI setup retain the limits in [0.3.0’s notes](https://github.com/bworlds-co/clodable/blob/clodable--v0.4.0/docs/releases/0.3.0.md).
