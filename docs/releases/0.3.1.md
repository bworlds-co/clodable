# Clodable 0.3.1

Released November 21, 2026. Connecting GitHub is easier to follow, saving errors give Claude the details needed to help, and Desktop panels have clearer headings, spacing and progress.

## What builders will notice

- **Guided GitHub connection.** The panel explains why GitHub is needed, shows the sign-in code with three steps, and offers a retry when an attempt does not finish. Code detection accepts both older and newer GitHub CLI wording. ([#118](https://github.com/bworlds-co/clodable/pull/118))
- **Useful help when saving fails.** Ask Claude for help supplies the failed step and its exact output. Claude can investigate local problems, while creating the private app and retrying setup remain explicit actions in the panel. Unexpected errors point to this help action. ([#118](https://github.com/bworlds-co/clodable/pull/118))
- **Progress that stops when work stops.** Saving and publishing name the current action without guessing a percentage. Completed steps remain visible, failed work loses its running indicator, and retry clears the previous saving error. ([#118](https://github.com/bworlds-co/clodable/pull/118))
- **Clearer Desktop panels.** Distinct headings, consistent spacing, quieter supporting text and a monospaced GitHub code make the controls easier to scan. Older engines keep compatible text and spacing. ([#118](https://github.com/bworlds-co/clodable/pull/118))

## Updating on another laptop

Update Clodable through Claude Desktop's plugin settings and check that its version is **0.3.1**. New Code conversations load the updated plugin. In an existing conversation, run `/reload-plugins --force`, then reopen Clodable. Restart an existing preview so it also uses the updated runtime.

For a command-line installation, run `claude plugin update clodable@clodable`. If the marketplace itself is pinned to an older release, use the repository's current marketplace at `https://github.com/bworlds-co/clodable`, then update again.

The plugin includes its own CLI. A separate npm installation is unnecessary for this Desktop test. The matching standalone package is `clodable@0.3.1`.

To test the fixes, open a local app, choose **Set up saving**, connect GitHub if needed, and check the named account before pressing **Create private app**. If saving fails, press **Ask Claude for help** in that same conversation.

## Verification and limits

The release checks cover lint, all package and plugin type checks, the build, 222 package tests and 161 plugin tests. The packaged CLI reports 0.3.1 and is identical to the plugin's bundled CLI. The npm package includes its own license and the notices for bundled dependencies.

Native Desktop checks on engine 2.1.328 exercised the sign-in code layout, saving failure/retry, publishing progress/failure, History, Settings and a roughly 470 px connected-account panel. Progress checks used local simulated operations. Earlier saving checks used a local fake GitHub destination, and the owner separately completed real GitHub authorization. That does not establish the cause of the original saving failure on the other computer; this release makes it easier to diagnose. Old-engine rendering is covered by version stubs, not a second installation of an old Desktop build.

The broader environment diagnostics discussed for a later update are not included. Real email delivery, hosted sign-in, AI configuration and a complete live migration retain the verification limits recorded in [0.3.0's notes](0.3.0.md).
