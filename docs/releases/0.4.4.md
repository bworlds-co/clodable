# Clodable 0.4.4

Released November 22, 2026. Clodable reuses an existing local GitHub connection
before asking you to sign in. This fixes
[#127](https://github.com/bworlds-co/clodable/issues/127).

## What builders will notice

- **Keep using your connected account.** An expired connection for another,
  inactive account no longer makes your active GitHub account appear disconnected.
- **No extra code when you are already connected.** If a connection becomes
  available while setup is open, Clodable checks it before requesting a sign-in
  code and shows which account it will use.
- **The same local connection.** Clodable uses the existing GitHub CLI connection
  or its environment token. This adds no hosted authentication service and does
  not import browser or Claude connector sessions. Without a usable connection,
  the existing GitHub sign-in remains available.

## Updating

Update Clodable in Claude Desktop's plugin settings, confirm **0.4.4**, and start a
new Code conversation. To reload an existing conversation, run
`/reload-plugins --force`. Restart any existing preview to load the new runtime.
The command-line equivalent is `claude plugin update clodable@clodable`.

The Desktop plugin includes its CLI. The release attaches
`clodable-plugin-0.4.4.zip`, the matching standalone `clodable-0.4.4.tgz`, and
`SHA256SUMS`. npm registry publication remains pending because this release
environment's npm authentication is rejected; no npm installation is needed for
Desktop.

## Verification and limits

All 346 package tests and 246 native plugin tests pass, with lint, builds and type
checks, including the plugin check against generated Claude types. The regression
tests reproduced both unnecessary sign-in cases before the fixes. Existing local
environment tokens, the connected account shown in setup, and the signed-out
fallback are also covered.

GitHub responses and plugin host interactions are simulated in these tests. A
fresh Desktop UI walkthrough and real GitHub authorization were not performed for
this patch.
