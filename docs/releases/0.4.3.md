# Clodable 0.4.3

Released November 21, 2026. Clodable now uses your Mac's primary language when
Claude Code's response language is unset. This fixes
[#120](https://github.com/bworlds-co/clodable/issues/120).

## What builders will notice

- **French without extra setup.** On a French Mac, Clodable's controls, preview,
  progress messages and requests to Claude use French when no response language
  is selected in Claude Code.
- **Claude's language stays first.** An explicit response language takes priority.
  Clodable supports the French and English catalogs and falls back to English for
  unsupported or unavailable languages. There is no separate language setting.
- **Changes are picked up in the conversation.** Clodable rereads the language
  preference as the conversation continues. A delayed lookup cannot replace a
  more recent selection. Your app's own language stays independent.

## Updating

Update Clodable in Claude Desktop's plugin settings, confirm **0.4.3**, and start a
new Code conversation. To reload an existing conversation, run
`/reload-plugins --force`. Restart any existing preview to load the new runtime.
The command-line equivalent is `claude plugin update clodable@clodable`.

The Desktop plugin includes its CLI. The release attaches
`clodable-plugin-0.4.3.zip`, the matching standalone `clodable-0.4.3.tgz`, and
`SHA256SUMS`. npm registry publication remains pending because this release
environment is not authenticated there; no npm installation is needed for Desktop.

## Verification and limits

All 342 package tests and 244 native plugin tests pass, with lint, builds and type
checks, including the plugin check against generated Claude types. The language
cases cover macOS preferences, explicit-setting precedence, failed lookups,
hosted and non-Mac sessions, retained conversations, overlapping refreshes, and
French propagation into the preview and requests to Claude.

The system fallback is read-only and limited to local macOS sessions. The native
plugin tests simulate host preferences; a fresh Desktop UI walkthrough and a full
live Lovable move were not rerun for this patch.
