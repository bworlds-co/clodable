# clodable

The command line behind [Clodable](https://github.com/bworlds-co/clodable): an open-source, Lovable-style app builder that runs on your own computer, on top of Claude Code.

You don't need to run it yourself. The Clodable plugin for Claude Desktop uses it to save your work, publish it, undo, and run your app's preview (`npx clodable dev`). To start, follow [Get started](https://github.com/bworlds-co/clodable#get-started) on GitHub.

For programs, every command takes `--json` and prints one event per line (NDJSON).
